# Query Parameters & Filtering

So far your list endpoints return everything. Real APIs filter, sort, and paginate results — and the mechanism for all of that is **query parameters**.

## req.params vs req.query

These two are easy to confuse, but they serve different purposes:

```js filename="server.js"
// req.params: /tasks/:id
app.get('/tasks/:id', (req, res) => {
  console.log(req.params.id) // '42' (always a string)
})

// req.query: /tasks?status=done&priority=high
app.get('/tasks', (req, res) => {
  console.log(req.query.status)   // 'done'
  console.log(req.query.priority) // 'high'
})
```

<Callout variant="warning" title="Query params are always strings">
`req.query.page` gives you `'1'` (string), not `1` (number). Always convert: `parseInt(req.query.page, 10)`.
</Callout>

## Filtering

The most common use case — filter a collection based on a field value:

```js filename="server.js"
// GET /tasks?status=done
// GET /tasks?priority=high
// GET /tasks?status=todo&priority=medium

app.get('/tasks', (req, res) => {
  const { status, priority } = req.query

  let result = [...tasks] // copy so we don't mutate the original

  if (status) {
    result = result.filter(t => t.status === status)
  }

  if (priority) {
    result = result.filter(t => t.priority === priority)
  }

  res.json({ data: result, total: result.length })
})
```

## Sorting

Accept a `sort` field and optional `order` direction:

```js filename="server.js"
// GET /tasks?sort=createdAt&order=desc
// GET /tasks?sort=priority&order=asc

app.get('/tasks', (req, res) => {
  const { sort, order = 'asc' } = req.query
  let result = [...tasks]

  if (sort === 'createdAt') {
    result.sort((a, b) => {
      const diff = new Date(a.createdAt) - new Date(b.createdAt)
      return order === 'desc' ? -diff : diff
    })
  }

  if (sort === 'priority') {
    const rank = { high: 3, medium: 2, low: 1 }
    result.sort((a, b) => {
      const diff = rank[a.priority] - rank[b.priority]
      return order === 'desc' ? -diff : diff
    })
  }

  res.json({ data: result, total: result.length })
})
```

## Pagination

For large datasets, you don't want to return everything at once. The standard pattern uses `page` and `limit`:

```js filename="server.js"
// GET /tasks?page=1&limit=10

app.get('/tasks', (req, res) => {
  const page = Math.max(1, parseInt(req.query.page ?? '1', 10))
  const limit = Math.min(100, Math.max(1, parseInt(req.query.limit ?? '10', 10)))

  const total = tasks.length
  const start = (page - 1) * limit
  const data = tasks.slice(start, start + limit)
  const pages = Math.ceil(total / limit)

  res.json({
    data,
    meta: {
      total,
      page,
      limit,
      pages,
      hasNext: page < pages,
      hasPrev: page > 1,
    }
  })
})
```

<Callout variant="tip" title="Cap the limit">
Always set a maximum on `limit` — otherwise a client could request `?limit=1000000` and bring down your server. `Math.min(100, limit)` caps it at 100.
</Callout>

## Combining Everything

Query params compose — clients can filter, sort, and paginate in a single request:

```
GET /tasks?status=todo&sort=priority&order=desc&page=1&limit=5
```

## Complete Handler

```js filename="server.js"
app.get('/tasks', (req, res) => {
  const { status, priority, sort, order = 'asc' } = req.query
  const page = Math.max(1, parseInt(req.query.page ?? '1', 10))
  const limit = Math.min(100, Math.max(1, parseInt(req.query.limit ?? '10', 10)))

  // 1. Filter
  let result = tasks.filter(t => {
    if (status && t.status !== status) return false
    if (priority && t.priority !== priority) return false
    return true
  })

  // 2. Sort
  const priorityRank = { high: 3, medium: 2, low: 1 }
  if (sort === 'createdAt') {
    result.sort((a, b) => {
      const diff = new Date(a.createdAt) - new Date(b.createdAt)
      return order === 'desc' ? -diff : diff
    })
  } else if (sort === 'priority') {
    result.sort((a, b) => {
      const diff = priorityRank[a.priority] - priorityRank[b.priority]
      return order === 'desc' ? -diff : diff
    })
  }

  // 3. Paginate
  const total = result.length
  const start = (page - 1) * limit
  const data = result.slice(start, start + limit)

  res.json({
    data,
    meta: { total, page, limit, pages: Math.ceil(total / limit) }
  })
})
```
